Task 5: Host a Static Website with GitHub Pages

Objective

Deploy a static HTML website using GitHub Pages.

Tools Used

- GitHub
- GitHub Pages
- HTML
- CSS

Implementation Steps

1. Created a GitHub repository for the internship task.
2. Created an "index.html" file with HTML and CSS.
3. Committed the website code to the "main" branch.
4. Configured GitHub Pages to deploy from "main" and the root folder.
5. Verified the website using the published URL.

Outcome

Successfully learned the process of hosting static website content using GitHub Pages.
